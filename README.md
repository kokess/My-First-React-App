# My First React App

An interactive React application built with Vite to practice functional components, JSX, props, state management with `useState`, event handling (`onClick` and `onChange`), and conditional rendering. It includes a counter with even/odd detection and reset functionality, plus a personalized greeting input with conditional styling and a current-year footer.
